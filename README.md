## Python Program

The program stores my name, creates a set of numbers, and prints the information in the terminal. It also calculates the sum of the numbers using Python's `sum()` function and displays my favorite course.

### Source Code

```python
name = "Luke Walters"
numbers = {18, 26, 3, 4, 5}

print("Student:", name)
print("Numbers:", numbers)
print("Total:", sum(numbers))
print("Favorite course:", "COT 2000C")
```

## Expected Output

The program displays my name, the set of numbers, their total, and my favorite course.

The total is **56**.
